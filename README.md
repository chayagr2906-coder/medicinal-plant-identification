# Medicinal Plant Identification Using Machine Learning

## Project Overview

This project aims to develop a computer vision and machine learning
based system for identifying different medicinal plants and raw
materials from images.

## Problem Statement

Identification of different medicinal plants and raw materials
through image processing using machine learning algorithms.

## Technology Domain

- Computer Vision
- Machine Learning
- Deep Learning
- Image Processing

## Objectives

- Collect and analyze medicinal plant image datasets
- Preprocess plant images
- Develop an image classification model
- Identify medicinal plants from input images
- Display the predicted plant information

## Dataset

The project will use publicly available medicinal plant image
datasets. The primary dataset under consideration is the Indian
Medicinal Leaves Image Dataset.
